# Greatjambo.github.io

Personal website of Chengbo Zhan, live at <https://greatjambo.github.io>.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme. Pushing to `master` triggers the `deploy` workflow, which builds the site and publishes it to the `gh-pages` branch.

- Home page content: `_pages/about.md`
- Profile photo: `assets/img/prof_pic.jpg`
- Name, email and social links: `_config.yml`
